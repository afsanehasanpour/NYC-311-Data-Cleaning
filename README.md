# NYC 311 Service Requests: Advanced Data Cleaning & Preprocessing

This project demonstrates a professional workflow for handling and cleaning large-scale public datasets using **Python** and **Pandas**. The analysis focuses on NYC 311 service requests, transforming raw, messy data into a structured format ready for analytical modeling.

## 🚀 Key Features
*   **Data Quality Audit:** Identified and handled missing values and inconsistent data types.
*   **Feature Engineering:** Converted date/time strings into datetime objects for temporal analysis.
*   **Noise Reduction:** Filtered out irrelevant columns and outliers to optimize memory usage and processing speed.
*   **Categorical Encoding:** Standardized "Complaint Types" and "Borough" information for consistency.

## 🛠 Tech Stack
*   **Language:** Python 3.x
*   **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
*   **Environment:** Jupyter Notebook
